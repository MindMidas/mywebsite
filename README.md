# **Pre-Requisites**

- Node.js 22.12+
- pnpm 11+

---

# **How to Build & Run**

```bash
pnpm install
pnpm dev
```

```bash
pnpm build
pnpm preview
```

---

# **Folder Structure**

```text
website/
|-- public/
|-- src/
|   |-- components/
|   |-- data/
|   |-- layouts/
|   |-- pages/
|   `-- styles/
|-- astro.config.mjs
|-- package.json
`-- README.md
```

Useful paths:

- `src/data/` — resume, projects, and site config
- `public/project-media/` — project images and demos
